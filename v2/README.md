# צמחי מרפא – גרסה 2 (עיצוב Materia Medica)

כתובת: https://golan-code.github.io/herbs-app/v2/
הגרסה הקודמת נשארת בכתובת הראשית עד לאישור.

## מסכים
- **בית** – לשוניות צמח / מצב-שימוש / מבט סיני, חיפוש, קיצורים לפי חלק הצמח, הצמח היומי, אחרונים שצפית.
- **תוצאות** – כרטיסים. החלקה ימינה או לחיצה על התמונה הקטנה פותחת בועת תמונה.
- **עמוד צמח** – תקציר, הריון והנקה, ארבעה אריחים (שימושים, בטיחות, מבט סיני, רכיבים), צמחים דומים, שיעור על הצמח.
- **הצמח היומי** – כל יום שיעור על צמח אחר: היכרות, שימושים, מבט סיני, בטיחות, נקודות לזכירה, שאלות לבדיקה עצמית, וסימון "נלמד".
- **מועדפים**, **מבט סיני** (סינון לפי איכויות ופעולות), **חיפוש** (החיפוש המלא של הגרסה הקודמת, עם אותן תוצאות בדיוק).

## מבנה הקבצים
```
firestore.rules          ← כללי האבטחה של Firebase (פרויקט golan-herbs-app)
tests/rules.test.mjs     ← בדיקות לכללים (npm run test:rules)
v2/
  admin.html, js/admin.js ← דף ניהול: קודי הזמנה והעלאת נתונים
  js/firebase.js         ← חיבור ל-Firebase
  js/access.js           ← בדיקת גישה ומסכי חסימה
  index.html, app.css, sw.js, manifest.webmanifest
  data/images.json       ← תמונות לכל צמח (לפי מזהה)
  data/lessons.json      ← שיעורים אישיים ל"הצמח היומי" (רשות)
  js/store.js            ← טעינת נתונים, מזהים, מועדפים ואחרונים
  js/search.js           ← חיפוש, סינון, דמיון סיני, בחירת הצמח היומי
  js/ui.js               ← אייקונים, כרטיס, חלונית, בועה, החלקה
  js/router.js, app.js   ← ניווט בין מסכים וסרגל תחתון
  js/screens/*.js        ← מסך לכל קובץ
```

## מזהה צמח
לכל צמח מזהה קבוע מהשם הלטיני: `Achillea millefolium` → `achillea-millefolium`.
מועדפים, תמונות, שיעורים, ובעתיד פורמולות ופתולוגיות, נשמרים לפי המזהה הזה ולא לפי מיקום ברשימה.

## הוספת תמונות
ב-`data/images.json`:
```json
{ "herbs": { "achillea-millefolium": ["img/yarrow-1.jpg", {"src": "https://…", "credit": "צילום: …"}] } }
```
אחרי כל שינוי מעלים את מספר הגרסה ב-`v2/sw.js` (`herbs2-v1` → `herbs2-v2`).

## הכנה להמשך
- **פתולוגיות**: קובץ `data/pathologies.json` עם רשימת פתולוגיות, ולכל אחת מזהי צמחים ודפוסים סיניים. מסך חדש `screens/pathologies.js`, שורה ב-`ROUTES` ובמידת הצורך ב-`NAV` (ב-`js/app.js`).
- **בניית פורמולות**: מסך `screens/formula.js`. פורמולה = שם + רשימת `{id, חלקים}`. נשמרת בטלפון דרך `store.js`, ונעזרת ב-`score()` ובתגיות `c` כדי להציג את האיכויות המשולבות של הפורמולה.
- **מקרה חי**: מסך שבו מזינים מקרה ואבחון לפי הגישה שלך. ההצעה של צמחים תשתמש באותו מנוע (`find`, `score`, תגיות סיניות) ובהמשך אפשר לחבר שרת בינה מלאכותית. זה ידרוש שרת ומפתח API, ולא רק אתר סטטי.

## תמונות אוטומטיות מ-Wikimedia Commons
לצמח שאין לו תמונות ב-`data/images.json`, האפליקציה מחפשת בעצמה (מהטלפון) תמונה חופשית לפי השם הלטיני:
תמונה ראשית מ-Wikipedia (רק ברישיון חופשי), ועוד עד שתיים מ-Commons כשפותחים את הבועה. התוצאות נשמרות בטלפון ל-30 יום, והתמונות נשמרות במטמון אחרי צפייה.
תמונה שנבחרה ידנית ב-`data/images.json` תמיד גוברת. הקוד ב-`js/commons.js`.

## גישת ניסיון והגנה על הנתונים
- נתוני הצמחים לא נמצאים בריפו. הם יושבים ב-Firestore (`content/*`) ונקראים רק על ידי:
  מנהל (כניסה עם Google), או מכשיר שמחזיק קוד הזמנה תקף, לא נעול ולא פג תוקף.
- קוד הזמנה: קישור `.../v2/?invite=CODE`. הקוד ננעל למכשיר הראשון שנכנס איתו (משתמש אנונימי של Firebase).
  ב-30 הדקות הראשונות מותר לעבור למכשיר אחר (למשל מ-Safari לאפליקציה המותקנת באייפון, שיש לה אחסון נפרד). אחרי זה רק "איפוס מכשיר" בדף הניהול.
- ניקוי נתוני הדפדפן נחשב מכשיר חדש, וצריך "איפוס מכשיר".
- דף הניהול: `.../v2/admin.html`. שם יוצרים קודים, נועלים, משחררים, מאריכים, מאפסים, מוחקים, ומעלים את `herbs-data.json`.
- דרך יצירת קשר במסכי החסימה: `CONTACT` בראש `js/access.js`.
