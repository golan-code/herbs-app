# אינדקס צמחי מרפא – גרסת אפליקציה (PWA)

## מה יש בתיקייה
- `index.html` – הדף עצמו (כ-16KB, בלי נתונים).
- `herbs-data.json` – כל הנתונים של 233 הצמחים. לעדכון תוכן עורכים רק את הקובץ הזה.
- `manifest.webmanifest`, `icons/` – מה שהופך את האתר לאפליקציה שאפשר להתקין.
- `fonts/` – הגופן Frank Ruhl Libre לשמות הצמחים, שמור מקומית כדי שיעבוד גם בלי אינטרנט.
- `sw.js` – שומר את הדף והנתונים בטלפון כדי שיעבדו בלי אינטרנט.

הקובץ המקורי `herbs-all.html` נשאר בתיקייה הראשית כגיבוי, ללא שינוי.

## למה לא לפתוח בלחיצה כפולה
דפדפנים חוסמים טעינת JSON ו-service worker מכתובת `file://`. צריך להגיש את התיקייה דרך שרת.

## בדיקה על המחשב
בטרמינל:
    cd ~/"צמחי מרפא/herbs-pwa"
    python3 -m http.server 8000
ואז לפתוח בדפדפן: http://localhost:8000

## התקנה בטלפון (מומלץ: GitHub Pages, חינם)
התקנה כאפליקציה ועבודה בלי אינטרנט דורשות כתובת https.
1. ב-github.com ליצור מאגר חדש (Public), למשל `herbs`.
2. Add file → Upload files, לגרור את כל התוכן של התיקייה `herbs-pwa` (כולל התיקייה icons), Commit.
3. Settings → Pages → Branch: `main`, תיקייה `/ (root)` → Save.
4. אחרי דקה-שתיים האתר זמין בכתובת `https://<שם-המשתמש>.github.io/herbs/`.
5. בטלפון:
   - אייפון (Safari): כפתור השיתוף → "הוסף למסך הבית".
   - אנדרואיד (Chrome): תפריט ⋮ → "התקן אפליקציה" / "הוסף למסך הבית".
6. לפתוח פעם אחת עם אינטרנט. מאז היא עובדת גם במצב טיסה.

הערה: אפשר גם Netlify Drop (גוררים את התיקייה לאתר app.netlify.com/drop) – מהיר יותר, אבל הכתובת זמנית אם לא נרשמים.

## עדכון נתונים בעתיד
1. לעדכן את `herbs-data.json` (או את `index.html`).
2. ב-`sw.js` להעלות את מספר הגרסה: `herbs-v1` → `herbs-v2`.
3. להעלות מחדש. בטלפון העדכון נקלט בפתיחה הבאה עם אינטרנט (לפעמים בפתיחה השנייה).

## מבנה רשומה ב-herbs-data.json
- `n` שם עברי, `lat` שם לטיני · אנגלי, `part` חלקים בשימוש, `p` קטגוריית חלק (לסינון)
- `eff` השפעות, `main` שימושים עיקריים, `sec` שימושים משניים
- `safe` בטיחות, `preg`/`nurse` – [צבע (ok/mid/bad), טקסט]
- `tcm` במבט סיני: רשימת `{q,v}` (איכויות/הערות) או `{a,li}` (פעולה ודפוסים)
- `comp` רכיבים פעילים: [1 = שורת משנה, טקסט]
- `c` תגיות סיניות לסינון ולדמיון: t טעם, m טמפרטורה, l לחות, a פעולות
- `s` (רק ב-24 צמחים) טקסט חיפוש מיוחד; בשאר הוא נבנה אוטומטית מהשדות
